# Competency Matrix

Avaliação honesta do estado atual do Second Brain por competência. O objetivo é **identificar lacunas**, não declarar domínio. "✓" indica que existe conteúdo consolidado nesta base; ausência de "✓" não é um julgamento sobre a pessoa, é sobre a cobertura da base até agora.

| Competência | Conhecimento (notas existem) | Integração (conectado a outras áreas) | Prática (cenário/exercício aplicado) |
|---|---|---|---|
| Java 21 | ✓ | ✓ | parcial (exercícios conceituais, sem projeto implementado) |
| Spring Boot | ✓ | ✓ | parcial |
| Hexagonal Architecture | ✓ | ✓ | parcial |
| Azure | ✓ | ✓ | não implementado (sem ambiente real provisionado) |
| Azure Monitor | ✓ | ✓ | não implementado |
| Application Insights | ✓ | ✓ | não implementado |
| Log Analytics | ✓ | ✓ | parcial ([[KQL Exercises]] conceituais) |
| KQL | ✓ | ✓ | parcial ([[KQL Exercises]] conceituais) |
| Observabilidade | ✓ | ✓ | parcial |
| Troubleshooting | ✓ | ✓ | parcial (cenários documentados, nunca executados contra sistema real) |

## Leitura da matriz

- **Conhecimento** e **Integração** estão consistentemente fortes — resultado direto das Etapas 1 a 10.
- **Prática** é a coluna mais fraca em toda a matriz: nenhum cenário foi executado contra uma aplicação real rodando no Azure. Todos os exercícios e cenários de troubleshooting são conceituais/simulados no papel.
- Isso é esperado e aceitável para esta fase — mas é a lacuna mais importante a registrar (ver [[Integration Gaps]]).
