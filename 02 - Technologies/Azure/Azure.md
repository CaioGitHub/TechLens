# Azure

MOC (Map of Content) — visão geral do Microsoft Azure a partir da perspectiva de um desenvolvedor backend Java/Spring Boot. O objetivo não é catalogar todos os serviços Azure, mas compreender como uma aplicação Java + Spring Boot pode ser executada, protegida, conectada, escalada e operada dentro do Azure.
