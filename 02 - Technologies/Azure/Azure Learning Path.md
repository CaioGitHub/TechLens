# Azure Learning Path

Sequência sugerida para estudar Azure a partir do conteúdo desta etapa. A ordem real de aprendizado pode variar conforme pré-requisitos práticos do projeto.

```
Cloud Fundamentals ([[Cloud Computing]])
       ↓
Azure Fundamentals ([[Azure Resource]], [[Azure Resource Manager]])
       ↓
Resource Groups ([[Resource Group]])
       ↓
Subscriptions ([[Azure Subscription]])
       ↓
Regions ([[Azure Regions]])
       ↓
Availability Zones ([[Azure Availability Zones]])
       ↓
Compute ([[Azure Compute]] → [[Choosing Azure Compute]])
       ↓
Storage ([[Azure Storage]])
       ↓
Database ([[Azure Databases]])
       ↓
Networking ([[Azure Networking]])
       ↓
Identity ([[Azure Identity]])
       ↓
Security ([[Azure Security Fundamentals]])
       ↓
Scalability ([[Azure Scalability]])
       ↓
Availability ([[Azure Availability]], [[RPO and RTO]])
       ↓
Deployment ([[Azure Deployment]], [[Infrastructure as Code]])
       ↓
Well-Architected ([[Azure Well-Architected Framework]])
       ↓
Spring Boot on Azure ([[Spring Boot on Azure]])
       ↓
Hexagonal Architecture on Azure ([[Hexagonal Architecture + Azure]])
       ↓
Observability (próxima etapa)
```
