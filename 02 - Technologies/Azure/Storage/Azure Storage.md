# Azure Storage

MOC para os principais serviços de armazenamento do Azure, hospedados dentro de uma Storage Account (o recurso "container" que agrupa os diferentes tipos de armazenamento).

## Tipos principais

- [[Blob Storage]] — armazenamento de objetos (arquivos não estruturados).
- [[Queue Storage]] — mensageria simples para desacoplamento assíncrono.
- **Table Storage** — armazenamento chave-valor/NoSQL simples (mencionado apenas como referência; não aprofundado nesta etapa).
- **Azure Files** — compartilhamentos de arquivo acessíveis via protocolo SMB/NFS (mencionado apenas como referência; não aprofundado nesta etapa).

## Relações

- [[Azure]]
- [[Azure Databases]] — para dados estruturados/relacionais/NoSQL com necessidade de consulta, prefira um banco de dados gerenciado em vez de Storage.
