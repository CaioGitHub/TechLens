# Spring Boot

## O que é

Spring Boot é a forma padrão, hoje, de construir e executar aplicações sobre o **Spring Framework**, priorizando convenções sensatas, configuração automática e execução simplificada sobre configuração manual extensiva. Ver [[Spring Framework vs Spring Boot]] para a relação entre os dois.

## Pergunta central desta etapa

> Como Spring Boot ajuda a construir e executar uma aplicação Java moderna, e como seus mecanismos podem ser utilizados sem destruir as fronteiras arquiteturais?

A resposta detalhada está em [[Spring Boot + Hexagonal Architecture]].
